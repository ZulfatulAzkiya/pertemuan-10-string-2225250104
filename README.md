## Deskripsi

Program ini dibuat untuk mempelajari pengolahan string dalam Python. Materi yang dipelajari meliputi penggunaan indeks, slicing, method string, pembersihan teks, pemisahan dan penggabungan kata, pencarian kata, serta normalisasi data mahasiswa.

## Daftar Program

1. `01_dasar_string.py` - Mengenal string dan panjang teks.
2. `02_indeks_slicing.py` - Mengakses karakter menggunakan indeks dan slicing.
3. `03_method_string.py` - Menggunakan berbagai method string.
4. `04_bersihkan_teks.py` - Membersihkan spasi pada teks.
5. `05_split_join.py` - Memisahkan dan menggabungkan kata.
6. `06_pencarian_kata.py` - Mencari kata dalam kalimat.
7. `tugas/normalisasi_data_mahasiswa.py` - Membersihkan dan menyeragamkan data mahasiswa.

## Cara Menjalankan

1. Buka folder proyek di Visual Studio Code.
2. Pastikan Python sudah terpasang.
3. Buka file Python yang ingin dijalankan.
4. Jalankan melalui tombol Run Python File atau terminal.

Contoh perintah:

```bash
python latihan/01_dasar_string.py
```

Untuk menjalankan tugas normalisasi data mahasiswa:

```bash
python tugas/normalisasi_data_mahasiswa.py
```
